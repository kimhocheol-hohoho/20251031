## 1. Dataset Overview

### 1.1 Structure and Coverage

The CSV file is organised with a two-row header: the first row enumerates metrics (`Open`, `High`, `Low`, `Close`, `Volume`) and the second row specifies the associated ticker symbol. Each subsequent row records end-of-day figures for a trading date. Parsing logic implemented in both analysis scripts ensures that missing values are skipped while preserving the rest of the record for downstream processing.

- **Trading window:** 2023-10-16 to 2025-10-10 (516 trading days ingested).
- **Tickers:** Samsung Electronics (005930.KS), Apple Inc. (AAPL), NVIDIA Corp. (NVDA).
- **Metrics captured:** Open, high, low, close, and traded volume per day for each equity.

### 1.2 Data Quality Diagnostics

`describe.py` reports the number of sessions lacking close prices for each ticker, yielding 34, 17, and 17 missing closes for 005930.KS, AAPL, and NVDA respectively. The script computes summary statistics—average close, extrema, average daily range, mean volume, best/worst daily return, and observation counts—ensuring that volatility and liquidity differences across markets are visible at a glance. A custom Pearson correlation implementation quantifies pairwise co-movement between the three equities, showing weak correlations between Samsung and the U.S. listings but a moderate positive relationship between Apple and NVIDIA.

### 1.3 Implications

The gap in available closes is most pronounced for the Korean listing, requiring cautious interpretation of cross-listed correlations. Nevertheless, the aligned daily ranges and volumes confirm that each ticker offers distinct risk-return characteristics, motivating diversification analysis.

## 2. Methodological Workflow

### 2.1 Descriptive Statistics Pipeline

1. **Load and parse:** `scripts/describe.py` loads `temp.csv`, materialises daily records, and segregates metrics by ticker.
2. **Summarise per asset:** For each ticker, the script computes means, extrema, ranges, and volume averages, while calculating one-day returns to identify the best and worst sessions.
3. **Missing data tracking:** During iteration, the script increments missing-close counters whenever a date lacks a closing price for a given ticker.
4. **Correlation analysis:** A manually implemented Pearson correlation coefficient assesses linear relationships between aligned return series.

The final output is a Markdown-formatted table and accompanying diagnostics that can be pasted directly into documentation.

### 2.2 Efficient Frontier Construction

1. **Data alignment:** `scripts/efficient_frontier.py` filters the dataset to rows with complete close information across all tickers, ensuring consistent return vectors.
2. **Return computation:** Daily simple returns are calculated from the aligned close matrix. The script prohibits zero-price denominators to guard against invalid data.
3. **Annualisation:** Returns and covariance are scaled by 252 trading days to express statistics in annualised terms.
4. **Frontier solution:** The script analytically inverts the covariance matrix and evaluates the efficient frontier for 50 evenly spaced target returns. It also computes the global minimum-variance portfolio weights.
5. **Visualisation:** A pure-SVG rendering routine maps volatility to the x-axis and return to the y-axis, drawing the frontier curve, individual asset markers, and an icon for the minimum-variance portfolio. Axis ticks and labels are generated dynamically to suit the observed ranges.

### 2.3 Reproducibility

Both scripts are standalone and rely solely on the Python standard library, simplifying execution in constrained environments. Each script exits gracefully when data prerequisites are not met (e.g., insufficient aligned closes), reducing the risk of silent miscomputations.

## 3. Analytical Findings and Recommendations

### 3.1 Key Results

- **Average performance:** Samsung's average close price exceeds ₩66,000 with relatively modest daily ranges, while Apple and NVIDIA show comparable USD ranges yet markedly different volumes, underscoring liquidity disparities.
- **Volatility spectrum:** NVIDIA experiences the widest swings in daily returns (−16.97% to +18.72%), signalling higher standalone risk.
- **Correlation patterns:** Apple and NVIDIA share a moderate positive correlation (≈0.37), suggesting shared market drivers, whereas Samsung remains largely uncorrelated with the U.S. equities.
- **Efficient frontier insight:** The efficient frontier arcs significantly below the individual asset points, confirming diversification benefits. The computed minimum-variance mix reduces risk below any single equity's annualised volatility while maintaining a return near the lower bound of the frontier.

### 3.2 Practical Recommendations

1. **Portfolio construction:** Investors seeking stability should consider the minimum-variance allocation derived from the frontier, as it offers lower volatility without sacrificing the baseline return of the least risky asset.
2. **Data maintenance:** Addressing missing close prices—particularly for Samsung—would improve the reliability of covariance estimates and allow for denser alignment across the sample.
3. **Scenario extensions:** Future work could incorporate currency conversion, transaction costs, or alternative risk measures (e.g., downside deviation) to reflect cross-market realities.
