Efficient frontier

Highlights

  • Samsung's low correlation with U.S. equities helps shift the frontier downward.
  • The star marks the global minimum variance allocation across the trio.

Reproduce the chart

  1. Install Python 3.10+ with the standard library.
  2. Run python scripts/efficient_frontier.py.
  3. Open figures/efficient_frontier.svg or revisit this page.
